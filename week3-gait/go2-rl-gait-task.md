## 3주차 — 팀별 핵심 기능 적용

**기한: 2026년 10월 4일**

### 보행팀: 학습한 Go2 보행 정책을 미로에 적용

#### 과제

Isaac Lab과 RSL-RL의 기존 Go2 보행 예제를 활용해 정책을 학습하고, 실행용 정책을 저장합니다. 이를 2주차 미로 환경에 적용하여 teleop으로 주행합니다.

목표는 **사용자의 속도 명령에 따라 걷는 정책을 학습하고 적용하는 것**입니다. 미로 경로를 스스로 찾는 정책 학습은 이번 과제에 포함하지 않습니다.

#### 제공되는 것

- 2주차 실행 환경과 호환되는 Go2 학습 예제 및 기본 설정
- 강화학습 기초, Isaac Lab, RSL-RL 관련 교보재
- 정책 학습·저장·내보내기·불러오기 예제
- 학습 정책을 기존 teleop에 연결하는 실행 예제
- GPU 사용 환경과 학습 시간 안내
- 제출해야 할 실행용 `.pt` 형식 안내

> 제공 자료: [실습 안내](guide.md) · [실행 예제와 교보재](preparation/README.md) · [예시 답안](Solution-HJ1/README.md)

학습에 사용한 관측·행동·보상의 기본 역할, 저장한 정책의 적용 방법, teleop 명령이 정책에 전달되는 흐름을 설명합니다. 성능 향상 자체보다 **직접 학습하고, 저장하고, 다시 불러와 실행하는 과정**을 확인합니다.
